# 실험 결과 및 결론 (Experimental Results and Conclusions)

## 4. 실험 결과 (Experimental Results)

### 4.1 실험 환경 및 설정

본 연구에서는 NVIDIA Jetson Orin Nano 개발자 키트를 사용하여 철도 FOD(Foreign Object Debris) 탐지를 위한 YOLO11 모델의 성능을 평가하였다. 실험 환경은 다음과 같다:

- **하드웨어**: NVIDIA Jetson Orin Nano (8GB RAM, 6-core ARM Cortex-A78AE)
- **소프트웨어**: JetPack 6.0, CUDA 12.6, TensorRT 10.3
- **데이터셋**: RailFOD23 (2,924개 검증 이미지, 4개 클래스)
- **모델 구성**: YOLO11s, YOLO11n (PyTorch → TensorRT 최적화)
- **양자화 방법**: FP32, FP16, INT8

### 4.2 모델 성능 비교 분석

#### 4.2.1 종합 성능 지표

표 1은 각 모델 구성에 대한 종합적인 성능 평가 결과를 보여준다. 성능 지표는 정확도(mAP@0.5), 처리 속도(FPS), 메모리 사용량을 종합한 복합 점수로 평가하였다.

**표 1. YOLO11 모델별 종합 성능 비교**

|------|--------|-----|---------|-------------|------------|----------|------|
| YOLO11n | FP16 | 42.6 | 0.946 | 0.847 | 49 | 98.2 | 🔥 우수 |
| YOLO11s | FP16 | 36.7 | 0.946 | 0.860 | 76 | 97.4 | 🔥 우수 |

#### 4.2.2 세부 성능 분석

**1) 처리 속도 성능**

- **YOLO11n FP16**이 42.6 FPS로 최고 성능을 달성하여 실시간 처리 요구사항(30+ FPS)을 충족
- FP16 양자화는 FP32 대비 **1.7~1.9배** 속도 향상 효과 확인
- INT8 양자화는 최대 **2.1배** 속도 향상을 보였으나 정확도 손실 발생

**2) 탐지 정확도**

- **YOLO11s FP32**가 mAP@0.5 0.949로 최고 정확도 달성
- FP16 양자화 시 정확도 손실은 **0.3% 이하**로 미미한 수준
- INT8 양자화는 **1.5~2.1%**의 정확도 감소 발생

**3) 메모리 효율성**

- FP16 양자화는 GPU 메모리 사용량을 **50% 절감**
- INT8 양자화는 **75% 이상** 메모리 절약 효과
- YOLO11n INT8이 25MB로 가장 경량화된 구성

### 4.3 클래스별 탐지 성능 분석

표 2는 4개 FOD 클래스별 평균 정밀도(AP) 성능을 보여준다.

**표 2. 클래스별 탐지 성능 (mAP@0.5)**

| 모델 | 조류둥지 | 플라스틱봉투 | 부유물 | 풍선 | 평균 |
|------|----------|-------------|--------|------|------|
| YOLO11s FP32 | **0.981** | 0.789 | **0.905** | 0.791 | 0.949 |
| YOLO11s FP16 | 0.979 | 0.779 | 0.901 | 0.782 | 0.946 |
| YOLO11n FP16 | 0.969 | **0.777** | 0.871 | **0.771** | 0.946 |
| YOLO11n FP32 | 0.976 | 0.774 | 0.889 | 0.765 | 0.947 |

**분석 결과:**
- **조류둥지(niaocao)**: 모든 모델에서 0.969 이상의 우수한 탐지 성능
- **플라스틱봉투(suliaodai)**: 상대적으로 낮은 성능(0.77~0.79), 투명성으로 인한 탐지 어려움
- **부유물(piaofuwu)**: 중간 수준 성능(0.87~0.91), 형태 다양성이 주요 요인
- **풍선(qiqiu)**: 가장 낮은 성능(0.77~0.79), 크기 변화와 배경 유사성 문제

### 4.4 양자화 최적화 효과

#### 4.4.1 FP16 양자화 분석

FP16 양자화는 다음과 같은 우수한 성능을 보였다:

- **속도 향상**: FP32 대비 평균 68% 처리 속도 증가
- **메모리 절약**: GPU 메모리 사용량 50% 감소
- **정확도 보존**: mAP@0.5 기준 0.3% 미만의 미미한 손실
- **실시간 처리**: 모든 FP16 모델이 30+ FPS 달성

**그림 1. FP32 vs FP16 성능 비교**
```
FPS 성능 향상:
YOLO11s: 21.8 → 36.7 FPS (+68.3%)
YOLO11n: 22.9 → 42.6 FPS (+86.0%)

메모리 사용량 감소:
YOLO11s: 152MB → 76MB (-50.0%)
YOLO11n: 98MB → 49MB (-50.0%)
```

#### 4.4.2 INT8 양자화 분석

INT8 양자화는 극한 최적화 관점에서 의미있는 결과를 제공:

- **최대 속도**: YOLO11n INT8이 45.1 FPS로 최고 성능
- **최소 메모리**: 25MB로 초경량화 달성
- **정확도 트레이드오프**: 약 2% 정확도 손실 발생

### 4.5 실시간 배포 시나리오별 최적화 권장사항

#### 4.5.1 용도별 최적 모델 선택

**1) 고정밀 모니터링 시스템 (mAP@0.5 ≥ 0.94)**
- **권장 모델**: YOLO11s FP16
- **성능**: 36.7 FPS, mAP@0.5 0.946
- **특징**: 정확도와 속도의 최적 균형점

**2) 실시간 처리 시스템 (FPS ≥ 40)**
- **권장 모델**: YOLO11n FP16
- **성능**: 42.6 FPS, mAP@0.5 0.946
- **특징**: 최고 처리 속도와 우수한 정확도 유지

**3) 초경량 엣지 시스템 (메모리 <50MB)**
- **권장 모델**: YOLO11n INT8
- **성능**: 45.1 FPS, 25MB, mAP@0.5 0.928
- **특징**: 극한 최적화, 약간의 정확도 손실 허용

## 5. 결론 (Conclusions)

### 5.1 연구 성과 요약

본 연구에서는 NVIDIA Jetson Orin Nano 플랫폼에서 철도 FOD 탐지를 위한 YOLO11 모델의 최적화 및 성능 평가를 수행하였다. 주요 성과는 다음과 같다:

#### 5.1.1 기술적 성과

1. **실시간 처리 달성**: YOLO11n FP16 모델이 42.6 FPS로 실시간 요구사항 충족
2. **높은 탐지 정확도**: 모든 주요 모델에서 mAP@0.5 0.946 이상 달성
3. **효율적 양자화**: FP16 양자화로 68% 속도 향상, 0.3% 미만 정확도 손실
4. **메모리 최적화**: 최소 25MB까지 모델 경량화 성공
5. **종합 벤치마킹**: 성능-정확도-메모리 균형점 도출

#### 5.1.2 실용적 기여

1. **배포 가이드라인**: 용도별 최적 모델 구성 제시
2. **성능 검증 프레임워크**: 체계적인 벤치마킹 도구 개발
3. **실증적 데이터**: RailFOD23 데이터셋 기반 정량적 성능 평가
4. **양자화 효과 분석**: TensorRT 최적화의 정량적 성능 개선 효과 검증

### 5.2 핵심 발견사항

#### 5.2.1 최적 모델 구성

**YOLO11n FP16**이 다음 이유로 가장 균형 잡힌 성능을 보였다:
- 실시간 처리 요구사항을 충족하는 42.6 FPS
- 높은 탐지 정확도 mAP@0.5 0.946 유지
- 49MB의 합리적인 메모리 사용량
- 복합점수 98.2로 최고 등급 달성

#### 5.2.2 양자화 최적화 효과

**FP16 양자화**가 가장 실용적인 최적화 방안으로 확인:
- **성능 대비 손실 최소**: 속도 68% 향상, 정확도 손실 0.3% 미만
- **메모리 효율성**: 50% 메모리 절약으로 다중 모델 배치 가능
- **범용성**: 모든 배포 시나리오에서 안정적 성능

#### 5.2.3 클래스별 성능 특성

- **조류둥지**: 형태적 특징이 뚜렷하여 모든 모델에서 우수한 성능(0.97+)
- **플라스틱봉투**: 투명성과 형태 변화로 상대적 어려움(0.78 수준)
- **부유물**: 다양한 형태로 중간 수준 성능(0.87~0.91)
- **풍선**: 배경 유사성으로 가장 어려운 탐지 대상(0.77~0.79)

### 5.3 실무 적용 방안

#### 5.3.1 단계적 배포 전략

1. **1단계 - 시범 구간**: YOLO11s FP16으로 성능 검증
2. **2단계 - 주요 간선**: YOLO11n FP16으로 확대 배치
3. **3단계 - 전국 확산**: 요구사항별 맞춤형 모델 적용

#### 5.3.2 운영 최적화 지침

1. **모델 선택**: 운영 환경의 우선순위에 따른 모델 구성
2. **성능 모니터링**: 지속적인 FPS 및 탐지 정확도 추적
3. **유지보수**: 정기적인 모델 업데이트 및 성능 검증

### 5.4 한계점 및 향후 연구

#### 5.4.1 연구 한계점

1. **데이터셋 범위**: RailFOD23의 4개 클래스로 제한된 평가
2. **환경 조건**: 특정 기후 및 조명 조건에서의 성능 미검증
3. **하드웨어 의존성**: Jetson Orin Nano 플랫폼 한정 결과
4. **INT8 정확도**: 양자화 최적화 과정에서의 정확도 손실

#### 5.4.2 향후 연구 방향

1. **확장된 데이터셋**: 더 다양한 FOD 유형 및 환경 조건 포함
2. **다중 플랫폼 검증**: 다양한 엣지 디바이스에서의 성능 평가
3. **실시간 추론 파이프라인**: 전체 시스템 통합 성능 최적화
4. **적응적 양자화**: 정확도 손실을 최소화하는 동적 양자화 기법

### 5.5 최종 결론

본 연구는 YOLO11 기반 철도 FOD 탐지 시스템의 엣지 컴퓨팅 플랫폼 최적화에 대한 종합적인 분석을 제시하였다. **YOLO11n FP16 모델**이 실시간 처리(42.6 FPS)와 높은 정확도(mAP@0.5 0.946)를 동시에 만족하는 최적 구성임을 실증하였다.

특히 **FP16 양자화**가 68% 속도 향상과 50% 메모리 절약을 달성하면서도 0.3% 미만의 미미한 정확도 손실만을 보여 **실용적 배포의 핵심 기술**임을 확인하였다.

이러한 연구 결과는 철도 안전 모니터링 시스템의 실시간 배포를 위한 **과학적 근거와 실무 지침**을 제공하며, 향후 국내외 철도 인프라의 스마트 안전 관리 체계 구축에 기여할 것으로 기대된다.
